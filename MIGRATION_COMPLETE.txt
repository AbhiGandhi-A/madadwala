                           NEXT STEPS - REQUIRED
═══════════════════════════════════════════════════════════════════════════════

1. SET UP ENVIRONMENT VARIABLES
   
   You need to provide:
   
   a) MongoDB Atlas Connection
      - Visit: https://www.mongodb.com/cloud/atlas
      - Create free account and cluster
      - Get connection string: mongodb+srv://user:pass@cluster.mongodb.net/...
      - Add to .env.local: MONGODB_URI=your-connection-string
   
   b) Gmail SMTP Configuration
      - Enable 2FA on your Google account
      - Go to: https://myaccount.google.com/apppasswords
      - Select "Mail" and "Windows Computer"
      - Copy the 16-character password
      - Add to .env.local:
        GMAIL_USER=your-email@gmail.com
        GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx
   
   c) JWT Secret
      - Generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
      - Add to .env.local: JWT_SECRET=your-generated-secret

2. CREATE .env.local FILE
   
   Copy from .env.example and fill in your values:
   
   MONGODB_URI=...
   JWT_SECRET=...
   GMAIL_USER=...
   GMAIL_APP_PASSWORD=...
   EMAIL_FROM=noreply@madadwala.com
   NEXT_PUBLIC_APP_URL=http://localhost:3000
   NODE_ENV=development

3. TEST THE SETUP
   
   npm install
   npm run dev
   
   Then visit: http://localhost:3000/login
   
   - Enter test email
   - Select Customer or Service Provider
   - Click "Send OTP"
   - Check email for 6-digit code
   - Enter code and login
   - Should redirect to home page

                         QUICK MONGODB SETUP
═══════════════════════════════════════════════════════════════════════════════

1. Go to: https://www.mongodb.com/cloud/atlas
2. Sign up for free account
3. Create a new project
4. Create a free M0 cluster (takes 2-3 minutes)
5. Create database user with password
6. Click "Connect" → "Drivers"
7. Copy connection string
8. Replace <password> with your database user password
9. Add to .env.local as MONGODB_URI

Example format:
mongodb+srv://myuser:mypassword@mycluster.mongodb.net/madadwala?retryWrites=true&w=majority

═══════════════════════════════════════════════════════════════════════════════
                        QUICK GMAIL SETUP
═══════════════════════════════════════════════════════════════════════════════

1. Go to: https://myaccount.google.com/security
2. Enable 2-Step Verification (if not already enabled)
3. Go to: https://myaccount.google.com/apppasswords
4. Select "Mail" and "Windows Computer"
5. Google generates 16-character password
6. Copy password (spaces are normal)
7. Add to .env.local:
   GMAIL_USER=your-email@gmail.com
   GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx (copy from Google)
